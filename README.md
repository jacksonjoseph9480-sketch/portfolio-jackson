# Jackson Joseph — Portfolio

A responsive, static portfolio for placement applications. It uses plain HTML, CSS, and JavaScript, so it needs no build step or package installation.

## Preview locally

Open `index.html` in a browser. The résumé download is included in `assets/` and works from the local site.

## Publish with GitHub Pages

1. Create a new public GitHub repository for the portfolio (or use a GitHub Pages repository).
2. Upload the contents of this folder, keeping `index.html`, `styles.css`, `script.js`, and `assets/` together at the repository root.
3. In the repository settings, open **Pages**, choose deployment from the `main` branch and `/ (root)`, then save.
4. GitHub Pages will display the published URL in the Pages settings when deployment completes.

Alternatively, drag this folder into Netlify Drop to publish a static preview.

## Updating the site

- Edit text and links in `index.html`.
- Edit the colors, layout, and responsive breakpoints in `styles.css`.
- `script.js` controls the small-screen navigation menu.
- Replace `assets/Jackson_Joseph_Resume.pdf` to update the downloadable résumé; keep the same filename or update the link in `index.html`.

The project descriptions and metrics are taken from the supplied résumé; the DocuMind AI description is also grounded in its public GitHub README. No live demo links are implied.
